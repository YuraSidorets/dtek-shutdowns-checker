# Find out.

Find shared electricity-on windows for three Kyiv addresses using DTEK schedules. Addresses are remembered in your browser.

[Open the site](https://yurasidorets.github.io/dtek-shutdowns-checker/)

## Run locally

Node.js 24+.

```powershell
npm install
npm run dev
```

Open http://127.0.0.1:43187. Run tests with `npm test`.
